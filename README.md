# Atmos — Weather Dashboard

A responsive weather dashboard built with vanilla HTML, CSS, and JavaScript. It fetches live conditions and a seven-day forecast from the free [Open-Meteo API](https://open-meteo.com/) and uses Open-Meteo's geocoding API for city search. No API key is required.

## Run locally

Open `index.html` in a browser, or serve this directory with any static web server. The browser needs an internet connection to retrieve forecasts. The optional “use my location” feature requires browser location permission and a secure context (HTTPS or localhost).

## Features

- Current conditions, humidity, wind, precipitation chance, and UV index
- Twelve-hour and seven-day forecasts
- City search with location suggestions
- Optional browser geolocation
- Celsius/Fahrenheit display toggle
- Responsive layout for desktop and mobile
